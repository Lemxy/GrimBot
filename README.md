## ✨ Возможности

| Модуль | Описание |
|---|---|
| ✅ **Верификация** | Кнопка в канале верификации выдаёт роль `Verified`, после перезапуска бота продолжает работать (persistent view) |
| 🎫 **Тикеты** | Выпадающий список категорий обращений создаёт приватный канал с доступом для автора и роли поддержки, закрывается по кнопке |
| 🧭 **Навигатор** | Единая приватная карточка с разделами: Тарифы, Гайды, FAQ, Библиотека игр — переключение без спама новыми сообщениями |
| 💎 **Тарифы** | Описание тарифов + картинка `tarif.png` + ссылка на FunPay для покупки |
| 📖 **Гайды** | Видео-инструкции по типовым проблемам (нет соединения со Steam, Steam не запускается) со списком доменов для исключений в антивирусе/файрволе |
| 🎮 **Библиотека игр** | Скриншоты по разделам Standard / Unique / Exclusive, подгружаются автоматически из папки `library_images` |

## 📦 Установка

```bash
git clone https://github.com/Lemxy/GrimBot.git
cd GrimBot

python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

## ⚙️ Настройка

1. Создай файл `.env` в корне проекта:

   ```env
   DISCORD_TOKEN=твой_токен_бота
   ```

2. В [Discord Developer Portal](https://discord.com/developers/applications) включи для бота интенты:
   - **Server Members Intent**
   - **Message Content Intent**

3. Добавь в `library_images/` скриншоты для библиотеки игр (см. [раздел ниже](#%EF%B8%8F-библиотека-изображений)) и картинку тарифов `tarif.png`.

4. При необходимости поправь под свой сервер константы в `GrimBot.py`: названия ролей, ссылку на FunPay, тексты тарифов/FAQ и т. д. (см. [Конфигурация](#-конфигурация)).

## 🛠 Команды администратора

Все команды требуют права **Administrator** и удаляют исходное сообщение-команду после публикации embed'а.

| Команда | Действие |
|---|---|
| `!setup_verify` | Публикует сообщение с кнопкой верификации |
| `!setup_tickets` | Публикует сообщение с выбором категории тикета |
| `!setup_navigator` | Публикует точку входа в навигатор |

│   ├── Unique1.png, Unique2.png

│   └── tarif.png
└── log.txt               # Локальный лог (не коммитится)

## 🖼️ Библиотека изображений

Файлы подбираются автоматически по **префиксу имени** (регистр не важен), расширение — `.png`, `.jpg`, `.jpeg` или `.webp`. Discord отправляет максимум 10 файлов за раз.

| Раздел | Префикс файла | Пример |
|---|---|---|
| 🟣 Стандартная (IRON) | `standard` | `Standard1.png` |
| 🟡 Уникальная (Gold/Diamond) | `unique` | `Unique1.png` |
| 🔵 Эксклюзивная (Diamond) | `exclusive` | `Exclusive.png` |
| 💎 Тарифы | `tarif` | `tarif.png` |

## 🔧 Конфигурация

Основные константы вынесены в начало `GrimBot.py`:

| Константа | Назначение |
|---|---|
| `VERIFIED_ROLE_NAME` | Имя роли, выдаваемой после верификации |
| `STAFF_ROLE_NAME` | Роль персонала с доступом ко всем тикетам |
| `TICKET_CATEGORY_NAME` | Категория, в которой создаются каналы тикетов |
| `FUNPAY_PROFILE_URL` | Ссылка на профиль FunPay для покупки тарифов |
| `STEAM_WHITELIST_DOMAINS` | Домены Steam для исключений в антивирусе/файрволе |
| `TICKET_CATEGORIES` | Категории обращений в тикет-системе |
| `GUIDES_SUBCATEGORIES` | Видео-гайды и привязанные к ним домены |
| `NAVIGATOR_CATEGORIES` | Разделы и тексты навигатора |
